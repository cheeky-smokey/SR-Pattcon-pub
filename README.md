# SRパタコン

> [!WARNING]
> ⚠️ **Work in Progress (WIP)** — 現在開発中・未完成のコードです。

シルバーリード社製の家庭用編み機向けの、編み図（パターン）の作成・転送システムです。

| 部品 | 内容 |
|---|---|
| **SRパタコン**（`app/`） | ブラウザで動くパターン編集アプリ。SRテキスト／U-BOX／PC10 形式の入出力と、WebSocket での機器への転送 |
| **M5キャリコン**（`firmware/KnitCtrl_M5/`） | M5Stack Core2・CoreS3 用のファームウェア。電子キャリッジの信号を読み、空通しで位置を合わせて、受け取ったパターンで選針する。LCD と音声で案内 |
| **キャリッジシミュレータ**（`firmware/SRCarriageSim/`） | Arduino UNO R4 用。編み機なしでコントローラを試すため、キャリッジの信号を作って選針を記録する |

```
パターン作成 → SRパタコン ──WiFi (WebSocket)──▶ M5キャリコン ──選針信号──▶ 編み機のキャリッジ
                                                   ▲ ONP / OCD / OPC / ON1
```

## 使い方

はじめての方は、まず [やさしい図解マニュアル（暫定版・PDF）](docs/SRパタコン_やさしい図解マニュアル_暫定版.pdf) をご覧ください。模様の作り方、パターン集への保存、PC10 用データの書き出し、iPad で CF カードへ入れる手順を図で説明しています。

### 1. SRパタコン

`app/SRパタコン多色1017_offline.html` をブラウザで開くだけで動きます（インストール不要）。編集したパターンは、メニューの「編み機コントロール」から M5キャリコンへ送ります。

### 2. M5キャリコン

1. Arduino IDE に **M5Unified** と **WebSockets**（Markus Sattler 作）をライブラリマネージャで入れる。
2. ボードは **M5Core2** または **M5CoreS3** を選ぶ。プログラムは約 1.8 MB なので、Partition Scheme が小さい設定のときは「16M Flash (3MB APP/9.9MB FATFS)」か「Huge APP (3MB No OTA)」にする。
3. `firmware/KnitCtrl_M5/KnitCtrl_M5.ino` を書き込む。
4. SD カードに次を置く。
   - `voice/` フォルダ（このリポジトリの `voice/` の中身。01〜24.wav）。ないときはブザー音で代わりに知らせる。
   - `wifi.cnf`（任意）。1行目に SSID、2行目にパスワードを平文で書く。ないときは SSID `SilverReed`／パスワード `12345678`。
5. WiFi につながらないときは、本体が設定用のアクセスポイント（`KnitCtrl-XXXX`）になります。LCD の QR コードで設定ページを開いて SSID を設定します。

操作の流れ: M5キャリコンが「SRパタコン接続待ち」になる → SRパタコンの編み機コントロールで接続 → **空通し**（キャリッジを端から端まで往復）で位置を合わせる → SRパタコンで送信開始。

本体のボタン（Core2 は画面下の丸、CoreS3 は画面下のタッチボタン）:

| ボタン | 働き |
|---|---|
| A | 空通しを始める |
| B | 空通しの開始側（右端⇔左端）を切り替える。接続待ちの画面では音量を下げる |
| C（短く押す） | 接続待ちの画面で音量を上げる |
| C（2 秒） | WiFi 設定ポータル |
| A + C（2 秒） | SRパタコンとのリンクを切り、接続待ちに戻る |

### 3. キャリッジシミュレータ

Arduino UNO R4 Minima / WiFi に `firmware/SRCarriageSim/SRCarriageSim.ino` を書き込み、M5キャリコンの信号ピンにつなぎます。結果は `tools/SRCarriageSim_viewer.html` で見られます。配線と使い方は [docs/SRキャリッジシミュレータ_詳細設計仕様書.md](docs/SRキャリッジシミュレータ_詳細設計仕様書.md) を参照してください。シミュレータとビューアは同じ版（1017）にそろえてください。

## キャリッジの信号とコネクタ

信号の名前は rev.43（2026-10-17）で次のように改めました。先頭の O はキャリッジから出る信号、I はキャリッジへ入る信号です。

| 名前 | 旧名 | 意味 |
|---|---|---|
| OCD | HOK | キャリッジ方向（Out Carriage Direction）。H = 左←右、L = 左→右 |
| ONP | CCP | 編み目カウント（Out Needle Pulse）。L→H の立ち上がりで 1 目進む |
| OPC | KSL | パターン出力フラグ（Out Point Cam）。H = ポイントカム有効区間 |
| ON1 | ND1 | カーソル（Out Needle 1）。カーソル通過でネガティブインパルス |
| INS | DOB | 選針（In Needle Select）。H = 平編み、L = 編み込み |

これはキャリッジから見た名前で、キャリッジシミュレータ（キャリッジの代わり）も同じ名前を使います。M5キャリコンでは、M5 から見た向きで I と O を付け替えた記号を使います（rev.44）。先頭の I は M5 へ入る信号、O は M5 から出る信号です。

| キャリッジ・シミュレータ | M5キャリコン | 意味 |
|---|---|---|
| OCD | ICD | キャリッジ方向 |
| ONP | INP | 編み目カウント |
| OPC | IPC | パターン出力フラグ（ポイントカム有効区間） |
| ON1 | IN1 | カーソル |
| INS | ONS | 選針 |

キャリッジのコネクタ（DIN 7 ピン メス）と XH 8 ピン（ケーブル色）の対応:

| 名称 | XH | ケーブル色 | DIN | 内容 |
|---|---|---|---|---|
| Vcc(5V) | 1 | 白 | 7 | 電源 5V |
| GND | 2 | 緑 | キー | GND |
| ソレノイドVcc(16V) | 3 | 黄 | 6 | 16V |
| ONP（針パルス） | 4 | 青 | 4 | L→H 立ち上がりパルス |
| OCD（向き） | 5 | 黒 | 5 | キャリッジ方向 H = 左←右、L = 左→右　|
| ON1（カーソル） | 6 | 赤 | 1 | カーソル（ネガティブインパルス） |
| OPC（選針区間） | 7 | 灰 | 2 | H = ポイントカム有効区間 |
| INS（選針） | 8 | オレンジ | 3 | 選針 H = 平編み、L = 編み込み |

## 配線（M5キャリコン）

| 記号 | キャリッジ側 | 向き | M5-Bus | Core2 | CoreS3 | 論理 |
|---|---|---|---|---|---|---|
| ONS（選針） | INS | 出力 | 16（R16） | G14 | G17 | L = 選針、H = 平編み（INS と同じ） |
| INP（針パルス） | ONP | 入力 | 15（L16） | G13 | G18 | L→H の立ち上がりで 1 目進む |
| ICD（向き） | OCD | 入力 | 21（L21） | G27 | G6 | H = 左←右、L = 左→右 |
| IN1（カーソル） | ON1 | 入力 | 4（R4） | G36 | G8 | L パルス = カーソルを通過 |
| IPC（選針区間） | OPC | 入力 | 22（R22） | G19 | G7 | H = パターンを出す区間 |

ソレノイドを TB67H450 のローサイドで直接駆動する場合の例（ここでは**案**です。実機で確認してください）:

- TB67H450 の IN2 を GND に固定し、TB67H450 の IN1 に M5 の ONS ピンをつなぐ。ONS ピンには 10 kΩ 程度のプルダウンを付ける（TB67H450 の IN1 と、M5 のカーソル入力 IN1 は別物）。
- ソレノイドの片側を Vcc、もう片側を OUT2 につなぐ（OUT1 は開放）。
- M5 が H のとき OUT2 が L になってソレノイド ON（選針）、L のとき出力は Hi-Z（OFF）になる。
- この配線では M5 の H でソレノイドを ON にするので、ファームの `ONS_ACTIVE_HIGH` を `true` にする（既定の `false` は、キャリッジの INS へつなぐときの設定）。

キャリッジ側の INS は「L（GND）= 選針（編み込み）、H（5V）= 平編み」です。M5 の ONS も同じ論理で出します（`ONS_ACTIVE_HIGH = false`。rev.46 で訂正。rev.45 までは H = 選針で出していました）。電源を入れてから M5 が起動するまでは ONS を駆動しないので、インタフェース側で H（平編み）にプルアップしてください。キャリッジの信号を M5 につなぐインタフェース基板を使う場合は、基板の論理に合わせて `ONS_ACTIVE_HIGH` を決めてください（論理を反転する基板なら `true`）。
